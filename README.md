# Dinitha Navanith — Portfolio

A bespoke, editorial portfolio website for **Dinitha Navanith** — UI/UX Designer & Software Engineer.

> *"I design thoughtful digital experiences and turn them into functional, user-focused products."*

---

## 🌟 Highlights & Architecture

- **Minimalist Editorial Theme**: Warm off-white canvas (`#f8f9fa`) with crisp white cards (`#ffffff`), hairline borders (`#e2e8f0`), deep slate typography (`#0f172a`), and royal electric blue accents (`#2563eb`).
- **3-Stage Symmetrical Hero**: Transparent portrait cutout with balanced brand badge on the left, headline on the right, and live trainee status.
- **Consistent 2-Column Split Grid**: Clear Swiss-style editorial layout with sticky section titles paired with content on the right.
- **Featured Works & Case Studies**:
  - `[01]` **Carpool** — Ride-sharing mobile UX & web platform
  - `[02]` **Student Enrolment** — Desktop management system (Java & MySQL)
  - `[03]` **Fitness Tracker** — Personal health telemetry & habit tracking (PHP & MySQL)
  - `[04]` **Mondy Cinema** — Cinematic movie discovery & seat reservation portal
  - `[05]` **MarketPulse AI** — Autonomous Telegram financial intelligence bot (Python & Gemini API)
  - `[06]` **Roadster Rush** — 2D canvas dynamic car racing engine
  - `[07]` **Web-to-Excel RPA** — Live Forex data ingestion & reporting bot
- **Human Micro-Interactions**: Smooth scroll reveal, custom magnetic cursor follower, and interactive modal case studies with zero dependency bloat.

## 🚀 Running Locally

Open `index.html` directly in any web browser, or serve it using Python:

```bash
# Start a local preview server
python -m http.server 3000
```

Then visit **`http://localhost:3000`** in your browser.
